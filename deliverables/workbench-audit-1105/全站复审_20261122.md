## 一、跨页横向问题

### A2（P2）主题切换按钮覆盖不齐 ⭐ 本轮最重要发现
- **现象**：`btnTheme`（统一口径：动作型文案 + 状态 SVG + aria-pressed + title）只存在于 5 页：任务台 / 明信片 / 海报墙 / 时间线 / home。**观剧 / 地图 / 随笔 / 作品集 4 页没有主题按钮**——它们有 dark token 与 O-7 初值跟随系统，但用户无法手动切换。
- **影响**：暗色系统用户站内体验割裂：在任务台切亮色，跳到随笔又变回暗色；亮色系统用户在 4 页永远看不到暗色。同一站内交互模型不一致。
- **建议**：给 4 页补统一口径的主题按钮（随笔/作品集是新页，头部结构现成，成本最低；观剧/地图头部略挤需排版微调）。涉及 4 页 HTML 字节变化 → APP_CACHE 顺延 + sw.js PRECACHE 不变。
- **涉及**：观剧记录.html / 旅行地图.html / 随笔.html / 作品集.html。

### B1（P3）跨页重复 helper 收敛空间
- **现象**：`toast()` 在 9 页各有 1 份实现、`esc()` 7 份、`uid()` 3 份、主题切换 IIFE 5 份、focus-trap 逻辑随笔/作品集各手写 1 份。改一处文案/缺陷需同步 N 页（v30 批二就为 toast 对比度同步了 4 页）。
- **建议**：在 O-9「单文件 + 继续抽共享块」框架内，把**与业务无关的纯工具**（toast / esc / 主题切换）抽入 SITE-NAV 注入块（全 10 页已注入）。注意 SHARED 铁律教训：顶层声明冲突、整块覆盖、注入后逐字节断言。**属可做但不急**，建议攒一次独立批次。

### B2（P3）响应式断点不统一
- **现象**：全站 17 种断点（360/400/420/460/480/560/640/680/700/720/760/820/860/861/900/980/1200）。任务台 7 个、海报墙 8 个、其余页集中在 560/680/900 一簇。
- **影响**：各页内部自洽、无实际破版；但维护心智不统一。
- **建议**：长期把主断点归拢为 560/680/900 三档；不必专门批次，随各页下次改动顺手归。

### B3（P3）标题层级（a11y）
- **现象**：任务台 / 明信片 / 海报墙三大页**没有 h1**（页面标题用 h2/dataTitle），屏幕阅读器页面大纲缺一级；随笔读弹窗往正文注入 `<h1>`（文章题）与页面 h1 层级冲突。
- **建议**：三大页页面标题升级为 h1；随笔读弹窗注入改 h2。

### B4（P3）全站无 meta description
- **现象**：10 页均无 `<meta name="description">`（仅 manifest 有描述）。分享卡片 / 搜索摘要缺失。
- **建议**：每页补一句页面级 description，一个批次顺手清。

### B5（P3）导出 revokeObjectURL 不一致
- **现象**：明信片 / 海报墙 / 随笔 / 作品集导出都做了「≥1s 延迟 revoke」（既定铁律）；**任务台 4 处导出（ICS / JSON / 统计报告 / 周小结）createObjectURL 后不 revoke**。频繁导出累积 Blob 引用（轻微泄漏，点完 a.remove() 影响有限）。
- **建议**：任务台 4 处照既有模式补 `setTimeout(()=>URL.revokeObjectURL(...),1000)`。
