## 二、发现与建议（按优先级）

### P1 · 根域名入口归属：index.html = 任务台，与「门户」叙事不匹配

- **涉及**：index.html、home.html、verify_release.py
- **问题**：迁移根域名后，`https://chy15164971.github.io/` 直接打开的是**重型任务台**（865KB、14 视图），而产品入口语义应是门户 home.html。品牌导航「工作台」logo 回的是 home.html，与根入口不一致；新访客首屏体验与「工作台门户」定位错位。
- **建议**：index.html 改为 **home.html 的逐字节副本**（替代现「index=任务台」契约）。PWA `start_url:"./home.html"`、manifest、导航全部不受影响，PRECACHE `"./"` 语义反而更准。
- **影响面**：需同步修改 verify_release.py 第 10/96 行铁律断言与 SHARED/A11Y_PAGES 清单语义（home 无弹窗不注入 MODAL-A11Y，副本后 index 同样不注入）；sw.js 升版本；三处副本同步口径从「任务台+index」变为「home+index」。
- **路由/菜单**：导航配置零改动。
- **备选**：若想保留「根=任务台」直达习惯，可不动，仅接受语义错位——列为建议而非缺陷。

### P2 · 任务台「进度」视图与海报墙：同一媒体生命周期两段式，无流转衔接

- **涉及**：任务管理台.html（data-v="media"，media.books/tvs/auds）、书影音海报墙.html（独立数据键）
- **问题**：任务台管理「在读/在追/在听」进行中进度（百分比），海报墙记录「已看/已读/已听」完成记录。同一部剧集可在两处分别录入：进度侧看完后需用户手动去海报墙再录一遍完成记录，**无双轨去重、无完成流转**。已核实任务台内「海报墙」引用全部是导航/菜单链接与注入注释，无数据互通。
- **建议**（二选一）：
  1. 加流转：任务台 media 条目加「✅ 看完」按钮 → 弹窗确认后写入海报墙记录（复用海报墙既有 `date` 字段口径与 ts 仲裁写入路径）；
  2. 维持现状但在两处 UI 加一句引导文案（如 media 视图空态注「完成后到海报墙留下记录」），成本最低。
- **影响面**：方案 1 需动任务台 + 海报墙公开写入函数（或共享块），P1-9 守卫会触发重冻；方案 2 仅文案。
- **路由/菜单**：无需改。

### P3 · v38 遗留文案陈旧（三处，一次小批次可清完）

1. **home.html 副标题自相矛盾**：hero 副标题「任务台 · 明信片追踪 · 书影音海报墙 · 观剧记录 · 旅行地图 · 时间线，**六个页面**共用一个入口」——漏随笔/作品集；而下方时间线卡已写「把**八个页面**里发生的事…」。属实漏改。
2. **home.html `<title>`**：「工作台 · 任务台 / 明信片 / 海报墙 / 观剧 / 地图 / 时间线」六页清单。
3. **manifest.json description**：「任务台 / 明信片追踪 / 书影音海报墙 / 观剧记录 / 旅行地图，共用一个入口」——六页时代文案；shortcuts 仅 5 项，可顺手补随笔/作品集（时间线是只读聚合页，不必进 shortcuts）。
- **影响面**：home 字节变 → sw.js 升版本 + 三处同步；manifest 变 → 同步。无逻辑改动，回归风险极低。
- **路由/菜单**：无需改。

## 三、无需调整项及判断依据

| 项 | 依据 |
|---|---|
| 观剧记录独立成页（不并回海报墙） | 记录粒度不同：观剧以「一场」为单位（剧场/票价/卡司），海报墙以「一部作品」为单位；观剧 5 tab 自闭环，含观演日历与想看流转 |
| 海报墙心愿单 vs 观剧「想看清单」双轨 | 领域不同（影音书 vs 舞台剧），且各自在同页内闭环流转（心愿→记录），无跨页搬运成本；合并反而造出跨域过滤复杂度 |
| 随笔 vs 地图日记 | 职责不同：随笔是独立文章（wb_notes_v1），日记绑定地点（IndexedDB）；时间线已按 note/diary 双源聚合，无重复入口 |
| 作品集 vs 海报墙（同为图片网格） | 动机相反：作品集是**创作产出**展示（设计/摄影/插画），海报墙是**消费记录**；UI 形态相似不构成职责重叠 |
| 媒体进度看板.html 跳转壳保留 | 禁用 JS 时 meta refresh 是唯一跳转手段（O-6 已裁定为渐进增强）；成本 1KB |
| 任务台 14 视图不拆分 | O-9 已裁定维持单文件（file:// 双击即用为产品前提）；当前 822KB/590 函数，未触重估阈值（>1.5MB / 页面>10 / FCP>1.8s） |
| 导航顺序（记录类→创作类→聚合类） | 现顺序：任务台（生产力）→ 明信片/海报墙/观剧/地图（兴趣记录）→ 随笔/作品集（创作输出）→ 时间线（聚合收尾），语义分组成立 |
| 时间线 9 源聚合 vs 首页概览 | 时间线是全量事件流（详情），首页是入口摘要（统计），粒度不同；首页已链接时间线卡，形成「摘要→详情」而非重复 |
